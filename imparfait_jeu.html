📖 Rappel : Les terminaisons de l'imparfait ▼

On prend le radical de nous au présent + terminaisons :

• je : -ais
• nous : -ions
• tu : -ais
• vous : -iez
• il / elle / on : -ait
• ils / elles : -aient

Seule exception de radical : Être ➔ radical ét- (j'étais).
