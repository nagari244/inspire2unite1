# CO_DELF_B1 – Compréhension de l'oral DELF B1

- `index.html` : page d'accueil (liste des activités 1 à 10 et scores).
- `activite01.html` … `activite10.html` : une page par activité.
- `delf-b1.js` : questions, transcriptions et logique (vérification, transcription, répéter, scores).

Déposer les pistes audio **dans ce même dossier**, avec ces noms exacts :
`DELFB1_activite01.mp3` … `DELFB1_activite10.mp3`
(si vos fichiers ne sont pas en .mp3, modifiez la ligne `audio:` de chaque activité dans `delf-b1.js`).
