Comment former le Futur Simple ?

Explication générale pour les verbes réguliers

1. Règle Générale (-ER et -IR)

On conserve l'infinitif complet et on ajoute les terminaisons uniques du futur simple :

Je → -ai (Je parlerai, Je finirai)
Tu → -as (Tu parleras, Tu finiras)
Il / Elle / On → -a (Il parlera, Elle finira)
Nous → -ons (Nous parlerons)
Vous → -ez (Vous parlerez)
Ils / Elles → -ont (Ils parleront)

2. Verbes terminés par -RE

Pour les verbes en -RE (comme prendre, attendre, lire, mettre), on supprime le -e final avant d'ajouter la terminaison :

  • Attendre → J'attendrai
  • Prendre → Nous prendrons
  • Lire → Vous lirez
  • Mettre → Elles mettront
✨ Rappel : Les terminaisons (-ai, -as, -a, -ons, -ez, -ont) sont identiques pour TOUS les verbes !

A) Classement des verbes irréguliers (4 groupes)

Le radical modifié reçoit les terminaisons habituelles (-ai, -as, -a, -ons, -ez, -ont).

Groupe -RR

  • Voir → verr-
  • Pouvoir → pourr-
  • Envoyer → enverr-
  • Courir → courr-
  • Mourir → mourr-

Groupe -VR

  • Devoir → devr-
  • Recevoir → recevr-
  • Pleuvoir → pleuvr-

Groupe -DR

  • Venir → viendr-
  • Tenir → tiendr-
  • Vouloir → voudr-
  • Falloir → faudr-
  • Valoir → vaudr-

Groupe Autres

  • Être → ser-
  • Avoir → aur-
  • Aller → ir-
  • Faire → fer-
  • Savoir → saur-
