Le participe passé

  • 1er groupe (-er) ➔ -é : manger ➔ mangé
  • 2e groupe (-ir, nous finissons) ➔ -i : finir ➔ fini
  • 3e groupe ➔ irréguliers : prendre ➔ pris, faire ➔ fait, voir ➔ vu, boire ➔ bu, lire ➔ lu, écrire ➔ écrit, venir ➔ venu, partir ➔ parti, sortir ➔ sorti, aller ➔ allé

Avoir ou être ?

La plupart des verbes se conjuguent avec avoir. Les verbes de la « maison d'être » (dans ce jeu : aller, venir, arriver, partir, sortir, rentrer, rester, tomber) se conjuguent avec être.

L'accord

Avec être, le participe passé s'accorde avec le sujet : +e (féminin), +s (pluriel), +es (féminin pluriel). Elle est partie. Ils sont venus.

Avec avoir, pas d'accord avec le sujet : Elles ont mangé.
