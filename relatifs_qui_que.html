Tableau Explicatif : Code Couleur Grammatical

Observez attentivement ce qui suit immédiatement le pronom relatif.

QUI Rôle : Sujet

Après QUI, on trouve directement le VERBE.

Exemple :

C'est le garçon qui pousse le ballon.

💡 pousse est le verbe conjugué dont "qui" est le sujet.

QUE / QU' Rôle : COD

Après QUE / QU', on trouve le SUJET (Nom/Pronom) + son VERBE.

Exemple :

C'est le ballon que Paul regarde.

C'est le ballon qu'il achète.

💡 Paul / il est le sujet et regarde / achète est son verbe.

Pronom Suivi immédiatement par... Exemple de la fiche
QUI Un verbe ...un fruit qui pousse à la Martinique.
QUE Sujet (consonne) + Verbe ...un fruit que vous devez manger.
QU' Sujet (voyelle/h) + Verbe ...les vitamines qu'il contient.

PDF - Ex. 2

Faites une seule phrase avec qui, que ou qu'.

Score Ex 2 : 0 / 2
1. Exemple guidé

Le bridge est un jeu de cartes.

  • a. Il exige une bonne mémoire visuelle.
  • b. Les enfants ne l'aiment pas.
👉 Phrase combinée : Le bridge est un jeu de cartes qui exige une bonne mémoire visuelle et que les enfants n'aiment pas.
2. À vous de jouer

Le Scrabble est un jeu.

  • a. Il développe la connaissance du vocabulaire.
  • b. On le pratique en famille ou entre amis.
3. À vous de jouer

Le jeu des sept familles est un jeu de cartes.

  • a. Les enfants l'adorent.
  • b. Il consiste à composer des familles.
